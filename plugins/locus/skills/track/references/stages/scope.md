# Scope

## Input

Maintenance work is neither a new capability nor incorrect behavior.

## Workflow

1. State the problem and proposed solution.
2. Add alternatives and context only when they improve the decision.
3. Identify the owner and deterministic acceptance evidence.

## Output

Proceed to Implement when the proportional work contract is understood and
approved at the depth the Task requires.

## Rules

- Match tracking depth to repository policy and explicit human intent.
