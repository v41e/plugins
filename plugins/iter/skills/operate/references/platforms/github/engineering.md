# GitHub Engineering Adapter

Load only for `engineering`.

## Evidence mapping

| Evidence                  | Command                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | Semantics                                                                                                                                                             |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Open Issues               | `gh issue list --repo OWNER/REPO --state open --limit 1000 --json number,title,labels,assignees,projectItems,createdAt,updatedAt,url`; fallback `gh api --paginate -X GET 'repos/OWNER/REPO/issues?state=open&per_page=100'`                                                                                                                                                                                                                                                                                                                           | REST `/issues` includes PRs; remove entries containing `pull_request`. A capped result is **Partial**.                                                                |
| Workflow failures         | `gh run list --repo OWNER/REPO --limit 1000 --json databaseId,workflowName,displayTitle,headBranch,headSha,event,status,conclusion,attempt,createdAt,updatedAt,url`; `gh run list --repo OWNER/REPO --commit HEAD_SHA --limit 100 --json databaseId,workflowName,headBranch,headSha,status,conclusion,attempt,createdAt,updatedAt,url`; `gh run view RUN_ID --repo OWNER/REPO --json databaseId,workflowName,headBranch,headSha,status,conclusion,attempt,createdAt,updatedAt,jobs,url`; `gh run view RUN_ID --repo OWNER/REPO --log-failed`; `gh api repos/OWNER/REPO/actions/runs/RUN_ID/attempts/ATTEMPT` | Read failed logs for diagnosis. Recent results do not prove full rerun coverage. A newer success supersedes a failure only for the same workflow, branch, and commit. |
| Project mapping and items | `gh project list --owner OWNER --limit 1000 --format json`; `gh project item-list NUMBER --owner OWNER --limit 1000 --format json`                                                                                                                                                                                                                                                                                                                                                                                                   | Resolve the live title-to-number mapping first. Keep exact `OWNER/REPO` items. Drafts need an explicit repository link or mapping; status does not prove approval.    |

Use selected Issue and PR detail commands from the root adapter after discovery.
