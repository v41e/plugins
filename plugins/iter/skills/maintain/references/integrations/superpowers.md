# Superpowers Method Mapping

The owning execution context selects matching installed methods. Track receives
their evidence; it does not run engineering work.

| Need | Installed method |
| ---- | ---------------- |
| Reproduced defect or unexpected behavior | `superpowers:systematic-debugging` |
| Changed behavior with a meaningful failing check | `superpowers:test-driven-development` |
| Execute an approved written plan | `superpowers:executing-plans` |
| Apply review feedback | `superpowers:receiving-code-review` |
| Required material review without equivalent evidence | `superpowers:requesting-code-review` |
| Current verification before claiming completion | `superpowers:verification-before-completion` |

Read only matching methods. Existing equivalent evidence need not be repeated;
missing plugins require no setup or replacement itinerary. Plans, worktrees,
delegation, and review ceremony follow actual need and repository policy.
