# Scope

## Purpose

Track a proportional Task problem, proposed solution, and execution authority.

## Input

A Task needing a proportional work contract, current direction, and any existing
Issue discussion or supporting evidence.

## Workflow

1. Use the existing Issue as the contract, or prepare a lightweight local draft
   for new work. Establish the problem, proposed solution, owner, and
   deterministic acceptance evidence. Include decisions, steps, alternatives, or
   context when useful.
2. Record proposed steps, existing scope/execution approval, separate
   publication scope, and unresolved material decisions. Reuse existing approval
   and discussion; contract Review owns the next decision. A settled low-risk
   correction needs no separate spec or plan.

## Output

Understood problem and solution, acceptance evidence, proportional steps,
authorization, and any unresolved material decision.

## Rules

- Missing solution or acceptance work returns to the owning context.
