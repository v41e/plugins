# EGM Artifact Discovery

Follow project instructions, work-record links, and the declared EGM artifact
directory before assuming a location. For projects using the shared `docs/`
layout, look under `docs/egm/<work>/` for concept briefs and the explicitly
named design, which can include its detailed plan. EGM's artifact directory and
final design destination can differ. Follow predecessor links to any standalone
plan.

These are discovery hints, not EGM's universal defaults or approval evidence.
Reading artifacts needs no installed plugin. Missing paths need no setup; report
material discovery gaps without manufacturing or relocating artifacts.
