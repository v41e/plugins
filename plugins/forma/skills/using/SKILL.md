# Using Forma

## Purpose

Guide code structure with concise problem/solution references.

## Skills

| Skill | Use for |
| ----- | ------- |
| `forma:shape` | Design new code, assess maintainability, or refactor existing code. |

Shape infers Design or Refactor mode from the request. Its references connect
smells, techniques, and patterns; assessments stay read-only.

## Requirements

Code or a requirement and the project's conventions. No setup or dependencies.
